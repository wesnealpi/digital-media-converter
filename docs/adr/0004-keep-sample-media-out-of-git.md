# ADR-0004: Keep sample media local and out of git

- **Status:** Accepted
- **Date:** 2026-09-17
- **Deciders:** Wes Watson

## Context

Testing needs real DVD, Blu-ray, and phone sources, which run from hundreds of megabytes to tens of gigabytes and are personal copies of commercial or private material. GitHub limits ordinary files to 100 MB, and Git LFS has bandwidth and storage quotas that a video test corpus would exhaust quickly.

## Decision

Sample media lives in `samples/` inside the working tree so tests can find it, but the folder has its own `.gitignore` that excludes everything except the ignore file and `README.md`. The root `.gitignore` also ignores common media extensions everywhere as a second guard. Tests treat samples as optional fixtures and skip cleanly when a folder is empty.

## Consequences

**Good**

- Samples sit next to the code with zero risk of an accidental upload.
- No LFS quota, no repo bloat, no licensing exposure.

**Bad / accepted costs**

- Tests that need media cannot run in CI or on a fresh clone; they are marked and skipped there.
- Reference outputs in `samples/expected/` must be regenerated by hand when settings change.

## Alternatives considered

- **Git LFS:** already installed, but quotas and the private nature of the sources rule it out.
- **Tiny synthetic clips in git:** useful for smoke tests and may be added later as a separate small fixtures folder, but they do not exercise real-world encoder behaviour.
